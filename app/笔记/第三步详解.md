## 零、整体流程

```
【同步流程】
点"同步" → 启动 TaskSyncService
              → 子线程 sleep 2000
              → sendBroadcast(ACTION_SYNC_FINISHED)
              → stopSelf()
列表页收到广播 → Toast "同步完成"

【提醒流程】
点"测试提醒" → 发送显式广播 ACTION_TASK_REMIND（带 task_id）
TaskReceiver.onReceive()
              → 创建通知渠道
              → 构建通知（PendingIntent 带 task_id）
              → notify()
点通知 → 打开 TaskDetailActivity，显示对应任务
```

两个流程**互相独立**，可以分开做、分开测。

## 二、第 1 步：TaskSyncService

新建 `service/TaskSyncService.kt`：

```kotlin
package com.example.todo_list.service

import android.app.Service
import android.content.Intent
import android.os.IBinder
import kotlin.concurrent.thread

class TaskSyncService : Service() {

    companion object {
        const val ACTION_SYNC_FINISHED = "com.example.todo_list.SYNC_FINISHED"
    }

    override fun onStartCommand(intent: Intent?, flags: Int, startId: Int): Int {
        // ⚠️ 必须开子线程：Service 默认运行在主线程，
        //    在主线程 sleep 会直接 ANR（应用无响应）
        thread {
            try {
                Thread.sleep(2000)      // 模拟耗时同步
            } catch (e: InterruptedException) {
                Thread.currentThread().interrupt()
                return@thread
            }

            // ⚠️ Android 8.0+ 对隐式广播有限制，
            //    必须 setPackage 变成显式广播，否则接收方收不到
            sendBroadcast(
                Intent(ACTION_SYNC_FINISHED).setPackage(packageName)
            )

            stopSelf()                  // 自己结束，否则会一直占着资源
        }

        // START_NOT_STICKY：被系统杀掉后不自动重启（我们只是一次性任务）
        return START_NOT_STICKY
    }

    override fun onBind(intent: Intent?): IBinder? = null
}
```

### 四个得分点

| 评分要求 | 对应代码 | 分值 |
|---|---|---|
| 点击可启动 Service | 由列表页 `startService()` | 1 |
| 模拟约 2 秒同步 | `Thread.sleep(2000)` 在子线程 | 2 |
| 完成后 `stopSelf()` | 子线程末尾调用 | 1 |
| 不直接操作页面 View | 用广播通知，Service 里没有 UI 代码 | 1 |

最后一条的关键是：**Service 里绝对不能出现 `binding`、`textView` 这类东西**。Service 和 Activity 生命周期不同步，直接改 UI 会崩。正确做法是发广播，让页面自己更新。

## 三、第 2 步：Manifest 注册

```xml
<manifest xmlns:android="http://schemas.android.com/apk/res/android">

    <!-- Android 13+ 通知权限 -->
    <uses-permission android:name="android.permission.POST_NOTIFICATIONS" />

    <application ...>

        <!-- ... 现有 Activity ... -->

        <!-- Service -->
        <service
            android:name=".service.TaskSyncService"
            android:exported="false" />

        <!-- Receiver -->
        <receiver
            android:name=".receiver.TaskReceiver"
            android:exported="false" />

    </application>
</manifest>
```

⚠️ 两个 `exported="false"` 都要写。含义是「不允许其他 App 启动我的组件」——你的 Service 和 Receiver 都是内部用的，设 false 更安全，也是 `targetSdk 31+` 的强制要求。

## 五、第 4 步：动态注册同步广播

在 `TaskListFragment` 里加：

```kotlin
import android.content.BroadcastReceiver
import android.content.Context
import android.content.Intent
import android.content.IntentFilter
import android.os.Build
import com.example.todo_list.service.TaskSyncService

class TaskListFragment : Fragment() {

    // 防重复点击的标志位（对应评分表"处理重复同步"1 分）
    private var isSyncing = false

    // 广播接收器
    private val syncReceiver = object : BroadcastReceiver() {
        override fun onReceive(context: Context?, intent: Intent?) {
            isSyncing = false
            Toast.makeText(requireContext(), R.string.msg_sync_finished, Toast.LENGTH_SHORT).show()
        }
    }

    override fun onViewCreated(view: View, savedInstanceState: Bundle?) {
        super.onViewCreated(view, savedInstanceState)
        setupRecyclerView()
        observeTasks()

        binding.addTaskFab.setOnClickListener {
            TaskEditActivity.startUI(requireContext())
        }

        binding.btnSync.setOnClickListener {
            startSync()
        }
    }

    private fun startSync() {
        if (isSyncing) return           // 同步中再点，直接忽略
        isSyncing = true
        requireContext().startService(
            Intent(requireContext(), TaskSyncService::class.java)
        )
    }

    override fun onStart() {
        super.onStart()
        // ⚠️ Android 13+ 必须指定 RECEIVER_NOT_EXPORTED 或 RECEIVER_EXPORTED
        //    不写会直接崩溃
        val filter = IntentFilter(TaskSyncService.ACTION_SYNC_FINISHED)
        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.TIRAMISU) {
            requireContext().registerReceiver(syncReceiver, filter, Context.RECEIVER_NOT_EXPORTED)
        } else {
            requireContext().registerReceiver(syncReceiver, filter)
        }
    }

    override fun onStop() {
        super.onStop()
        // ⚠️ 必须注销，否则报 IntentReceiverLeaked（广播接收器泄漏）
        requireContext().unregisterReceiver(syncReceiver)
    }
}
```

### 三个得分点

| 要求 | 实现 | 分值 |
|---|---|---|
| Service 正确发送广播 | Service 里 `sendBroadcast` | 1 |
| 列表页能接收广播 | `onStart` 注册 | 1 |
| 收到后显示提示 | `onReceive` 里 Toast | 1 |
| 处理重复同步 | `isSyncing` 标志位 | 1 |

### 为什么用动态注册

| 方式 | 评价 |
|---|---|
| **动态注册**（`onStart`/`onStop`） | ✅ 推荐。页面在才接收，天然避免泄漏，也不受隐式广播限制 |
| 静态注册（Manifest） | Android 8.0+ 对隐式广播有限制；且页面销毁后仍会收到 |

**记住成对出现**：`onStart` 注册 ↔ `onStop` 注销。忘了注销 Activity/Fragment 销毁时会报 `IntentReceiverLeaked`。

## 六、第 5 步：TaskReceiver + 通知

`receiver/TaskReceiver.kt`：

```kotlin
package com.example.todo_list.receiver

import android.app.NotificationChannel
import android.app.NotificationManager
import android.app.PendingIntent
import android.content.BroadcastReceiver
import android.content.Context
import android.content.Intent
import android.os.Build
import androidx.core.app.NotificationCompat
import com.example.todo_list.R
import com.example.todo_list.ui.detail.TaskDetailActivity

class TaskReceiver : BroadcastReceiver() {

    companion object {
        const val ACTION_TASK_REMIND = "com.example.todo_list.TASK_REMIND"
        const val EXTRA_TASK_ID = "task_id"
        const val EXTRA_TASK_TITLE = "task_title"

        private const val CHANNEL_ID = "task_reminder"
        private const val CHANNEL_NAME = "任务提醒"
    }

    override fun onReceive(context: Context, intent: Intent) {
        if (intent.action != ACTION_TASK_REMIND) return

        val taskId = intent.getLongExtra(EXTRA_TASK_ID, -1L)
        val title = intent.getStringExtra(EXTRA_TASK_TITLE).orEmpty()
        if (taskId == -1L) return

        showNotification(context, taskId, title)
    }

    private fun showNotification(context: Context, taskId: Long, title: String) {
        val notificationManager =
            context.getSystemService(Context.NOTIFICATION_SERVICE) as NotificationManager

        // ① 创建通知渠道（Android 8.0+ 必须，否则通知不显示）
        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.O) {
            val channel = NotificationChannel(
                CHANNEL_ID, CHANNEL_NAME, NotificationManager.IMPORTANCE_HIGH
            )
            notificationManager.createNotificationChannel(channel)
        }

        // ② PendingIntent：点通知进详情页
        val contentIntent = Intent(context, TaskDetailActivity::class.java)
            .putExtra(TaskDetailActivity.EXTRA_TASK_ID, taskId)
        val pendingIntent = PendingIntent.getActivity(
            context,
            taskId.toInt(),                    // requestCode 用 taskId，不同任务通知互不覆盖
            contentIntent,
            PendingIntent.FLAG_UPDATE_CURRENT or PendingIntent.FLAG_IMMUTABLE
        )

        // ③ 构建并发出通知
        val notification = NotificationCompat.Builder(context, CHANNEL_ID)
            .setSmallIcon(R.mipmap.ic_launcher)
            .setContentTitle(title)
            .setContentText(context.getString(R.string.msg_reminder_content))
            .setContentIntent(pendingIntent)
            .setAutoCancel(true)               // 点击后自动消失
            .setPriority(NotificationCompat.PRIORITY_HIGH)
            .build()

        notificationManager.notify(taskId.toInt(), notification)
    }
}
```

### 五个得分点

| 要求 | 实现 | 分值 |
|---|---|---|
| 正确创建通知渠道 | `NotificationChannel` | 1 |
| 成功显示通知 | `notify()` | 1 |
| 处理 Android 13+ 权限 | 见第 6 步 | 1 |
| 通知内容含任务信息 | `setContentTitle(title)` | 1 |
| 点击通知进对应详情页 | `PendingIntent` 带 `task_id` | 1 |

### 三个必踩的坑

**① `FLAG_IMMUTABLE`（Android 12+ 强制）**

```kotlin
PendingIntent.FLAG_UPDATE_CURRENT or PendingIntent.FLAG_IMMUTABLE
```

少了 `FLAG_IMMUTABLE` 会直接崩溃报 `Targeting S+ (version 31+) requires FLAG_IMMUTABLE or FLAG_MUTABLE`。

**② 通知渠道 ID 必须是常量**

```kotlin
private const val CHANNEL_ID = "task_reminder"   // ✅ 固定
```

不要每次生成随机 ID——那样每发一条通知就新建一个渠道，用户设置里会看到一堆垃圾渠道。重复创建**同名**渠道是安全的（系统会自动忽略）。

**③ `onReceive` 不能做耗时操作**

`onReceive` 运行在主线程，**超过 10 秒 ANR**。这里只做发通知（毫秒级），符合规范——对应评分表「onReceive 中不执行耗时任务」**2 分**。

另外 `TaskDetailActivity.EXTRA_TASK_ID` 现在是 `private`，需要改成 `const val` 公开（去掉 `private`）。

## 七、第 6 步：Android 13+ 通知权限

⚠️ **这 1 分最容易丢**。不加的话在 Android 13+ 设备上通知**完全不显示**，而你可能一直以为代码写错了。

在详情页（或 MainActivity）加权限申请：

```kotlin
// TaskDetailActivity 里
private val requestNotificationPermission =
    registerForActivityResult(ActivityResultContracts.RequestPermission()) { granted ->
        if (!granted) {
            Toast.makeText(this, R.string.msg_notification_permission_denied, Toast.LENGTH_SHORT).show()
        }
    }

private fun ensureNotificationPermission(onGranted: () -> Unit) {
    if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.TIRAMISU) {
        when {
            ContextCompat.checkSelfPermission(this, Manifest.permission.POST_NOTIFICATIONS)
                    == PackageManager.PERMISSION_GRANTED -> onGranted()
            else -> requestNotificationPermission.launch(Manifest.permission.POST_NOTIFICATIONS)
        }
    } else {
        onGranted()     // Android 13 以下不需要申请
    }
}
```

需要的 import：

```kotlin
import android.Manifest
import android.content.pm.PackageManager
import android.os.Build
import androidx.activity.result.contract.ActivityResultContracts
import androidx.core.content.ContextCompat
```

## 十、常见错误

| 现象 | 原因 | 解决 |
|---|---|---|
| 点同步后卡死 / ANR | 在主线程 `Thread.sleep` | 放进 `thread { }` |
| 同步完成但没 Toast | 没 `setPackage`，广播收不到 | Service 里加 `.setPackage(packageName)` |
| 崩溃：`requires FLAG_IMMUTABLE` | PendingIntent 缺标志 | 加 `or FLAG_IMMUTABLE` |
| 崩溃：动态注册广播报错 | Android 13+ 缺导出标志 | 加 `RECEIVER_NOT_EXPORTED` |
| `IntentReceiverLeaked` | `onStop` 没注销 | 补 `unregisterReceiver` |
| 通知完全不显示 | Android 13+ 没申请权限 | 见第 6 步 |
| 通知不显示（8.0+） | 没建渠道 | 加 `NotificationChannel` |
| 点通知进了错误任务 | `requestCode` 用了固定值 | 改成 `taskId.toInt()` |
| 多个通知互相覆盖 | `notify()` id 固定 | 改用 `taskId.toInt()` |
